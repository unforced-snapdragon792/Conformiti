## 📝 Features

Conformiti provides tools to keep your SaaS product secure and compliant. Use these features to organize your daily work:

Tasks Tracker: Create to-do lists for your audit team. Set due dates for every security control.

Document Vault: Upload audit evidence files. The tool organizes these files by standard type, such as SOC2 or ISO 27001.

Progress Dashboard: View your compliance status at a glance. Identify bottlenecks before they cause delays in your audit timeline.

User Permissions: Control who sees your audit data. Grant access to your team members and revoke it when necessary.

Data Backups: Save your audit progress to your local drives. You control where your data lives.

## 🏗️ Managing Your Audits

Compliance requires regular effort. Use the main window to monitor current audits. Click on any active audit to see the list of tasks. Each task shows the owner, the deadline, and the required evidence.

Submit your files directly into the task window. Conformiti saves the file and marks the task as ready for review. Your team can then check the work and move the task to the finished column. This workflow ensures that no documentation goes missing during the audit process.

## 🛠️ Settings and Configuration

Click the gear icon in the top right corner to change settings. You can switch between light and dark themes. You can also update your profile information or change the location folder for your stored audit files.

The software checks for updates when you start it. If an update exists, click the notify button to install the latest version. This keeps your compliance tools current with new security standards.

## 🚑 Troubleshooting

If you encounter issues during installation or usage, check these common fixes:

- The app does not open: Restart your computer and try to open the app again.
- Files do not upload: Check your internet connection. Ensure you have network access to the server folders.
- Permission errors: Open Conformiti as an administrator by right-clicking the icon and choosing "Run as administrator."
- Data loading slow: Close other large applications to free up your memory.

If you find a bug, report it on the GitHub issues page. Explain what happened, what you expected to happen, and which version of Conformiti you use. Include a screenshot if possible to help our team understand the problem.
